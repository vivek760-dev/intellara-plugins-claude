# Create Project Skill

Read ./template/STRUCTURE.md for the full standard folder/file structure.

When the user wants to start a new project:
1. Ask for the project name and target directory (if not given).
2. Read ./template/STRUCTURE.md to get the canonical structure.
3. Create that folder/file layout at the target directory.
4. Fill in placeholder files (README, config) with project-specific values.
5. Confirm the final structure with the user before finishing.
6. Create folders only when user needs it.
